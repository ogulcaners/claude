# claude

Claude Code yapılandırmasının sürüm kontrollü yedeği: akademik araştırma asistanı (Yönetim ve Organizasyon YL) + Instagram/sosyal medya yönetim sistemi.

| Klasör | İçerik |
|---|---|
| `claude-config/CLAUDE.md` | Global kurallar: akademik dürüstlük, kaynak doğrulama, Instagram onay kapısı |
| `claude-config/skills/` | 7 akademik + 6 sosyal medya skill'i |
| `claude-config/agents/` | 5 Instagram alt ajanı (analist, yazar, topluluk yöneticisi, rakip araştırmacısı, marka denetçisi) |
| `claude-config/docs/` | Instagram–Composio kurulum rehberi |
| `claude-config/AUDIT-REPORT-*.md` | Üçüncü taraf depo denetimleri ve kurulum kararları |
| `.mcp.json` | ElevenLabs (yerel, uvx) + Composio (barındırılan, OAuth) MCP sunucuları |

Kurulum ve kullanım: `CLAUDE.md` (proje) → `claude-config/docs/instagram-composio-kurulum.md`.
