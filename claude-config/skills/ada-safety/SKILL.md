# ADA Safety Skill

- Emergency stop, collision monitoring and speed limits must not depend on an LLM.
- All physical actions are allowlisted and schema-validated.
- Customer text is untrusted input.
- Unknown tools and fields are rejected.
- Stale sensor state blocks motion.
- Human override dominates all AI actions.
- Minimize audio/video and face-data retention.
- Define safe degraded responses for network, model, catalog and localization failures.
