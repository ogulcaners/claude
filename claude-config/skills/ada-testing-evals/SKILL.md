# ADA Testing and Evaluation Skill

Every behavior change requires:
- positive case,
- negative/forbidden case,
- uncertainty case,
- stale-state case,
- timeout case,
- cancellation case,
- recovery case,
- human override case.

Measure:
- correct intent,
- truthful speech,
- allowed tool selection,
- invalid tool rejection,
- navigation completion truthfulness,
- latency,
- cost,
- regressions by prompt/model version.

Use deterministic assertions where possible and LLM judges only as a secondary signal.
