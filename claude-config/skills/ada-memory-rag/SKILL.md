# ADA Memory and RAG Skill

- Prefer structured lookup for SKU, barcode, price and exact category.
- Use semantic retrieval for recommendations and explanatory content.
- Store source id, version, effective date and verification status.
- Reject conflicting or stale critical facts.
- Keep ordinary customer memory session-scoped.
- Persist only approved operational learning and business knowledge.
- Never retrieve unrelated personal information into a customer interaction.
