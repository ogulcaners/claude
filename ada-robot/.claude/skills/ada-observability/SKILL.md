# ADA Observability Skill

Each turn must be replayable from:
- prompt/config versions,
- normalized input,
- robot/world state,
- retrieved knowledge ids,
- proposed and validated actions,
- tool results,
- recovery path,
- final speech.

Track p50/p95 latency, model cost, navigation success, recovery rate, face uncertainty,
escalation rate, guessed-answer violations and failure reason codes.
Redact private data before broad log access.
